Eenmalige Firebase-inrichting

Deze module gebruikt dezelfde Firebase-aanmelding als de toernooi-app. Het account heeft de Firebase-claim role: "admin" of admin: true nodig. Voeg de volgende regels toe binnen match /databases/{database}/documents in het project bcr-toernooi.

function isDeelnemersAdmin() {
  return request.auth != null && (
    request.auth.token.get('role', '') == 'admin' ||
    request.auth.token.get('admin', false) == true
  );
}

match /deelnemers/{spelerId} {
  allow read, create, update, delete: if isDeelnemersAdmin();
  match /toernooien/{toernooiId} {
    allow read, create, update, delete: if isDeelnemersAdmin();
  }
}

match /deelnemersImports/{toernooiId} {
  allow read, create, update: if isDeelnemersAdmin();
}

Voor samenvoegen is delete nodig op deelnemers en hun toernooiresultaten. Voeg dit ook toe als je de regels eerder hebt ingesteld.

Controleer ook of bredere regels toegang geven tot deze paden. Test in de Firebase Rules Playground dat uitgelogde gebruikers en gewone gebruikers geen deelnemersgegevens kunnen lezen of wijzigen.
